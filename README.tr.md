# C++ Modül 07 — 42 Piscine

C++ şablonları: fonksiyonlar, sınıflar ve tip-agnostik programlama. Şablon yetkinliği için üç egzersiz.

| Ex | Bileşen | Konsept |
|---|---|---|
| ex00 | `swap`, `min`, `max` | Fonksiyon şablonları |
| ex01 | `iter` | Callable ile template fonksiyon |
| ex02 | `Array` | Sınır kontrolü olan template sınıf |

**Kazanımlar:**
- Fonksiyon şablonu özelleştirme ve aşırı yükleme
- Template tip parametresi çıkarımı
- Non-type template parametreleri
- Sınır dışı erişimde istisna fırlatan template sınıf
- Template bağlamda `const` doğruluğu

## Derleme

```bash
cd cpp7/ex00 && make && ./whatever
```
