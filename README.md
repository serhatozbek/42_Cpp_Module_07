# C++ Module 07 — 42 Piscine

C++ templates: functions, classes, and type-agnostic programming. Three exercises building template fluency.

| Ex | Component | Concept |
|---|---|---|
| ex00 | `swap`, `min`, `max` | Function templates |
| ex01 | `iter` | Template function with callable |
| ex02 | `Array` | Template class with bounds checking |

**Outcomes:**
- Function template specialization and overloading
- Template type parameter deduction
- Non-type template parameters
- Template class with exception on out-of-bounds access
- `const` correctness in template context

## Build

```bash
cd cpp07/ex00 && make && ./whatever
```
